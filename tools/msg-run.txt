============================================================================
  象棋强软 v1.3.1   一键源码运行验证
============================================================================

本脚本不依赖任何 exe，直接在源码目录执行  go run .  启动软件，
窗口会立即弹出，供你验证 v1.3.1 的修复效果。

  重要：本脚本不会生成任何 exe，所有产物都只留在工程目录内。
        验证满意后，再双击「构建exe.bat」生成最终的单文件 exe。

----------------------------------------------------------------------------
  启动后建议按下面的顺序逐条验证
----------------------------------------------------------------------------
  1. 默认窗口下棋盘完整（红黑双方全部棋子可见），底部两行操作栏都看得见：
     上面一行是「坐标输入框 + 应用」，下面一行是
     「悔棋一步 / 撤销全部 / 重开 / 手动摆盘 / 复制最佳着法」。
  2. 用鼠标点棋盘上的棋子，能准确选中并显示合法落点（绿色圆点），不再点不中。
  3. 在坐标输入框粘贴  h2e2 h9g7 c3c4  回车，局面正确应用、引擎自动分析。
  4. 点「复制最佳着法」，剪贴板里是 4 字符 UCI 坐标，并有中文提示。
  5. 点「引擎管理」：引擎应显示绿色的「可用」，不再误报「文件已丢失」；
     四个按钮「测试连接 / 设为己方引擎 / 设为对手引擎 / 移除」全部可见可点；
     窗口底色是护眼米黄，不是纯黑。
  6. 切到「引擎对战」：线程分配区能看到超订警告，点「按核心数自动平均分配」
     后双方各 8；对战线程之和超过 16 会给出醒目提示。
  7. 拖动棋盘与右栏之间的分隔条：分隔条变宽、悬停会高亮，能一次拖到位。
  8. 窗口标题栏完整可见（顶部不越界）；把窗口拉小，棋盘等比缩小不裁切，
     底部操作栏始终保留。

----------------------------------------------------------------------------
  退出方式
----------------------------------------------------------------------------
  直接关闭软件窗口即可，本控制台窗口随后也会结束。

----------------------------------------------------------------------------
  如果启动失败
----------------------------------------------------------------------------
  1. 源码编译报错：往上翻看 go 打印的错误行号。
  2. 提示找不到 go：请先安装 Go 1.22 或更高版本
        winget install GoLang.Go
     安装完成后关闭本窗口，重新双击本脚本。
  3. 文件被占用：先关闭已经在运行的「象棋强软」窗口。
  4. 依赖没下载全：在本目录执行  go mod download  后重试。
  5. 想确认源码本身是否健康，在本目录执行：
        go vet ./...
        go test ./...
