# 多引擎同局面对比分析（Kibitzer）设计稿

> **状态：设计已定稿（用户 2026-10-08 确认两处默认值）**
>
> - 时间语义：**同步每步时限**（一个输入框管两个引擎；不做「每引擎各填一套时制」）
> - 结果显示：**默认上下堆叠**（另给左右分栏开关）
>
> 实施分三阶段，见文末「六、分阶段实施」。

> 依据：同类产品完整调研（ChessBase/Fritz、Arena、Lucas Chess 官方帮助与源码，逐条附来源），
> 结论见本文末「调研要点」。**中文象棋软件没有等价功能**（象棋巫师的「副引擎」只用于引擎对战），
> 做出来是本软件的差异化点。

## 一、命名与入口（对齐行业）

| 位置 | 用词 | 依据 |
| --- | --- | --- |
| 主引擎 | 「引擎分析」 | 现状 |
| 第二引擎 | 「**参考引擎（Kibitzer）**」 | 行业统称 Kibitzer（ChessBase / Arena / Lucas Chess 都用这个词） |
| 入口 | 菜单「引擎 → 参考引擎（Kibitzer）…」+ 分析半栏引擎卡右上角「＋」 | 同类产品入口都在「引擎/窗口」菜单里 |

## 二、设置怎么排（**照同类范式，不要自创**）

三层结构，与 Arena 完全一致：

```
引擎 → 参考引擎（Kibitzer）…
┌─ 引擎 A（主）────────────────────────┐
│ 引擎 [Pikafish ▾]                    │   ← 沿用「引擎设置」里那套（线程/哈希/UCI 选项）
│ Multi-PV 行数 [3]                    │
├─ 引擎 B（参考）──────────────────────┤
│ [√] 启用参考引擎                      │
│ 引擎 [第二个引擎 ▾]                   │
│ [√] 线程/哈希跟随主引擎（推荐）        │   ← 取消勾选才单独填
│     线程 [4]  哈希 [512] MB           │
├─ 共用默认（勾选即强制覆盖所有引擎）────┤   ← 照 Arena 的 UCI 全局 Tab
│ [ ] 统一哈希 [1024] MB                │
│ [ ] 统一残局库路径 [           ]       │
└──────────────────────────────────────┘
```

**时间语义只做二选一（关键修正）**：

| 模式 | 说明 | 依据 |
| --- | --- | --- |
| **自由分析**（默认） | 两个引擎都无限时算，各自手动停 | ChessBase 引擎窗口「无限分析、手动停」 |
| **同步每步时限** | 一个输入框管两个引擎（如各 2 秒一步，算完自动停） | Arena 自动分析强制 `time per move`；报告明确「同类无『每引擎各填一套时制』的做法」 |

> ⚠ 我最初的设计是「每个引擎各填一套时间/深度」，**调研否掉了它**：同类产品里时间语义是统一的，
> 逐引擎独立的只有 UCI 参数、线程、哈希、Multi-PV 行数。本稿已按调研修正。

默认值抄 swiftxiangqi：线程 `max(1, min(4, 核数/2))`、哈希 128MB、Multi-PV 行数 3。

## 三、主界面怎么显示（只放结果）

每个引擎**一张等高卡片**：

```
┌─ 引擎 A · Pikafish（底色 A）── 算 · 先行 ─┐
│ 分数 +22    深度 18(24)   用时 1.0s   3,380 kn/s │
│ 主变例：馬八进七 卒7进1 馬二进三 …        [±] │
└──────────────────────────────────────────────┘
┌─ 引擎 B · 佳佳（底色 B）── 算 ────────┐
│ 分数 +15    深度 16(20)   用时 1.0s   2,910 kn/s │
│ 主变例：炮二平五 马8进7 …                [±] │
└──────────────────────────────────────────────┘
```

- **排布两个预设**：上下堆叠（默认）/ 左右分栏；再加「合并视图」把两引擎同深度行并排，便于逐行比分
  （Arena 的 `Aggregated view` 思路）。
- **引擎标识**：卡头底色固定区分（A 色 / B 色），照 Arena 的「引擎名带底色」。
- **只在启用 ≥2 个引擎时**才显示「先行方」标记（照 Arena 的 `To move indicator`）。
- **逐引擎三键**：暂停 / 停止 / **锁定当前局面**（锁定语义抄 ChessBase/Arena：钉住局面不受走子影响，
  用于「一个引擎继续算旧局面、另一个跟棋盘走」）。

## 四、本软件的差异化（同类都没做的）

1. **结论分歧可视化**：两引擎首选着法不同时——棋盘上同时画两支箭头（红/蓝对应卡头底色），
   两张卡头各加「分歧」徽标；
2. **分值差 ≥100 厘兵**时给分值加色底（照 ChessBase「评估下滑标红」的思路）。

## 五、必须提示用户的两件事（同类产品的明确警告）

- 多引擎**共享 CPU**，每加一个引擎分析质量都会下降 → 首次开启弹一行提示，并建议
  线程各设 `⌊核数/引擎数⌋`；
- 别给每个引擎都开大哈希（系统会换页）→ 统一哈希默认给 512MB 而不是各自拉满；
- 提供一键切换「**改用单引擎 Multi-PV**」（在「看多个候选」上等效且更省资源，宜作默认路径）。

## 六、分阶段实施（建议）

| 阶段 | 内容 | 说明 |
| --- | --- | --- |
| 1 | config 字段（``kibitzer_engine`` / ``kibitzer_follow_main`` / ``kibitzer_threads`` / ``kibitzer_hash`` / ``kibitzer_sync_ms``）+ 参考引擎设置入口 + 第二个引擎客户端生命周期 | 看不到效果但必须打底 |
| 2 | 分析循环同时向两个引擎发同一局面 + 分析半栏两张结果卡（**上下堆叠**） | 这一步就能用了 |
| 3 | 左右分栏 / 合并视图、分歧可视化（双箭头 + 卡头徽标）、逐引擎 暂停/停止/锁定 | 体验完善 |

**已确认的默认值**：同步每步时限 **2.0 秒**（Arena 自动分析同款语义）；结果**上下堆叠**；
参考引擎线程/哈希默认**跟随主引擎**（取消勾选才单独填）。

## 调研要点（来源摘要）

- **ChessBase 18 / Fritz 18**：`Add Kibitzer`（Ribbon「Home – Default Kibitzer」、菜单「Window – Add Kibitzer」、**Ctrl-K**，最多 6 个）；每个引擎单独设 Engine parameters 与 Hash table size；引擎窗口自带 Multi-PV ± 与「分数/深度/时间/nps」行；评估下滑标红；整窗布局可存可载。
  <https://help.chessbase.com/CBase/18/Eng/000084.htm> · <https://help.chessbase.com/CBase/18/Eng/engine_window.htm> · <https://help.chessbase.com/CBase/18/Eng/hash_tables.htm>
- **Arena**：最多 8 引擎并行（`Engines Manage` 设为 Active Engines → 导航栏 Analyze）；逐引擎 `Ctrl+1/Ctrl+2` 配置，另有 Tab「UCI」放共用 hash/表库（勾选即强制覆盖，引擎无法覆盖）；自动分析强制 `time per move`；分析区支持 单列堆叠 / `Two columns` / `Equal size` / `Aggregated view` 四种排布与字段开关；引擎名带底色；`To move indicator` 仅在 ≥2 引擎时显示；右键 `Analyse only with Engine X` / `Cancel calculating` / `Pause` / `Lock`。
  <https://www.playwitharena.de/>（官方 english.chm → Engines → Analysis Lines / Engine Management）
- **Lucas Chess**：`Utilities → Kibitzers`，一个 kibitzer = 一个引擎 + 一套监听内容（Candidates 默认 / Best move / Threats / Stockfish evaluation），独立窗口。
  <https://lucaschess.pythonanywhere.com/static/pdf/english/Lucas%20Chess%201-Play.pdf>
- **swiftxiangqi**（单引擎，设置骨架可借）：Settings → Engine tab（Threads / Hash 64~1024MB）+ Analysis 分组（Lines shown 1~5，默认 3）；默认 `threads=max(1,min(4,核数/2))`、`hash=128MB`。
  <https://github.com/yancunz/swiftxiangqi>
- **中文象棋软件**：象棋巫师「加载副引擎/副引擎执红」仅用于**对战**且副引擎不自动加载；天机象棋/鹏飞象棋可加载多引擎但按开/中/残局**切换**而非并行对比。
  <https://www.xqbase.com/xqwizard/help_computer.htm>
